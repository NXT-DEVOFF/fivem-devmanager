## Vidéos

| Fichier | Format | Description |
|---|---|---|
| `video/fivem-devmgr-teaser-vertical.mp4` | MP4 H.264, 1080 × 1920, 15 s, ~8 Mo, sans audio | Teaser vertical pour Discord, TikTok, Reels et Shorts |

GitHub affiche le lecteur en ouvrant le fichier vidéo dans le dépôt. Les fichiers restent téléchargeables directement.
